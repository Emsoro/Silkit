# 像电子表格一样，安全地编辑数据库表

写 SQL 改数据谁都会，难的是「改错了能全身而退」。Silkit 的表格视图把这件事做得足够克制：既能像电子表格那样随手编辑，又把安全网织在了每一步背后。

## 双击即编辑

在左侧对象树里双击任意表或视图，就能打开一个虚拟滚动的可编辑网格。分页、排序、搜索、筛选（操作符 + 值 + AND 组合）都直接可用，不用先写一条查询。

## 它先确认「能不能安全改你」

打开表时，Silkit 会自动探测行标识：优先用主键，其次唯一非空索引，SQLite 还可以用 `rowid`。只有能唯一定位到某一行的表，才允许编辑；没有安全标识的表会自动变为只读，并明确告诉你原因——避免你凭空写 `UPDATE` 却忘了 `WHERE`。

## 编辑状态机

- 新增行、删除行、单元格内联编辑；
- 脏单元格、新增行、删除行分别以不同颜色高亮；
- 工具栏提供 新增 / 删除 / 保存 / 撤销 / 刷新 / 精确计数。

## 保存前先看清 SQL，保存时兜住风险

点击保存时，Silkit 会先展示将要执行的 INSERT / UPDATE / DELETE 语句预览。确认后，它在事务中执行整批修改；如果其中任意一条失败（例如违反唯一约束），**整批回滚**，并把错误定位到具体的出错行。你不会得到「改了一半」的表。

## 不只是格子

- 单元格查看器：双击或右键打开长文本、JSON、图片、HEX 视图，并支持另存；
- 复制 / 区域选择 / TSV 复制；
- 一键复制为 SQL 或 INSERT 语句，方便贴回聊天工具或文档。

把「随手改」和「敢改」结合起来，正是 Silkit 表格视图想做的事。
