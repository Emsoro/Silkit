# Silkit：一个原生、轻量的跨数据库工作台

如果你同时维护 SQLite、MySQL 和 PostgreSQL，大概率被各种网页后台、命令行客户端和臃肿的 Electron 工具来回切换折磨过。Silkit 想解决的就是这件事：一个原生桌面应用，把三种数据库的工作流统一到同一套界面里。

## 它是什么

Silkit 是一个面向开发者的跨数据库工作台，使用 C++ 与 WebView2 构建，最终产物是一个不依赖运行时、可直接分发的单文件可执行程序——没有 Electron 的体量与内存开销，启动即用。

当前已支持：

- **SQLite / MySQL / PostgreSQL** 三种引擎统一管理；
- 安全的连接配置（可加密保存密码、只读连接、事务性开关）；
- 对象树：库、表、视图、索引、触发器一目了然，可一键刷新；
- SQL 编辑器：基于 CodeMirror，支持语法高亮、字段/关键字补全、SQL 格式化、执行范围（选中 / 当前语句 / 全部）；
- 流式结果：多结果分页子标签、CSV / JSON 导出、三引擎 EXPLAIN 执行计划；
- 历史记录与片段：快速复用常用语句；
- 标签持久化：关闭再打开，工作区自动恢复。

## 最让我满意的一点：安全地编辑表数据

很多工具让你直接 `UPDATE` 却不给你后悔药。Silkit 的表格视图会在保存前展示将要执行的 SQL，并在事务中执行；一旦某一行出错（比如唯一键冲突），整体回滚，并精确告诉你哪一行出了问题。对生产库动手之前，这种安全感很重要。

## 开源与跨平台

Silkit 以开源方式发布，Windows 为首要支持平台，后续会向更多平台扩展。如果你也受够了在多个数据库客户端之间反复横跳，不妨试试看。

> 项目仍在快速迭代中，表格设计器（建表 / 改表 DDL 可视化）已在规划路线中。
